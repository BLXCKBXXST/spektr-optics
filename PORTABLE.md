# «Спектр» — автономный файл

Дата: 6 октября 2026 года.

Для запуска нужен **только `portable/spektr.html`**. Его можно скопировать отдельно на другое устройство и открыть в браузере. Интернет, сервер, установка программы, Node.js, Python и загрузка библиотек не требуются. Код, оформление и рисунок установки находятся внутри файла. Файл не обращается в сеть; политика безопасности дополнительно запрещает сетевые подключения.

Это переносная версия текущего визуального прототипа. Физическая достоверность формы и яркости спектра ещё не проверена; последующие этапы разработки остаются в `SIMULATOR_PLAN.md`. Старые `simulator-site/dist` и архив не заменялись, публикация не выполнялась.

## Как открыть

1. Скопировать `spektr.html` на нужное устройство.
2. Открыть файл в полноценном браузере, при необходимости через «Открыть с помощью».
3. Если появляется только предпросмотр файла или текст кода, это не запуск в браузере. Возможность открытия локального HTML зависит от системы и приложения; просмотрщик вложений может не выполнять JavaScript.

Требуется браузер с JavaScript и Canvas 2D. WebGL/WebGPU не используются. Стиль Windows XP — только оформление, а не обещание поддержки старых браузеров эпохи Windows XP. Буквальная совместимость с любым устройством, любой ОС и любым объёмом памяти не гарантируется.

## Управление и сохранение

- Все три галочки, фильтры, ракурсы и стрелки доступны без наведения мыши.
- Экран двигается мышью или пальцем в общем/верхнем видах; шаг 1 мм. Стрелки переходят к следующему числу, кратному 10, в выбранном направлении.
- В крупном виде экран не перетаскивается. При включённых «Значениях» линейка следует за мышью; после касания пальцем остаётся на выбранном месте.
- При доступном локальном хранилище браузер запоминает состояние. Если хранилище запрещено, программа продолжает работать без сохранения между открытиями. Сохранённое состояние не переносится вместе с файлом на другое устройство; начальная позиция там — 250 мм.
- Рисунок обновляется только по событиям. Разрешение расчёта модели ограничено, а при медленном расчёте дополнительно уменьшается; подписи интерфейса рисуются отдельно. Это снижает нагрузку, но не отменяет минимальные требования браузера к памяти и процессору.

## Проверка и поддержка разработки

Проверка выполняется локально в Chromium через `file://`, включая режим без сети/GPU/WebGL, узкие окна, сенсорное управление и недоступное локальное хранилище. Эмуляция мобильного экрана не доказывает совместимость с конкретным телефоном. Safari, Firefox и реальные Android/iOS-устройства в этой среде не проверены.
