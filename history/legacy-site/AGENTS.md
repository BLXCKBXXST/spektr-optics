# Инструкции для продолжения разработки

Это браузерный симулятор лабораторной работы 7.3 по дифракции света.

## Главный принцип

Симулятор имитирует оборудование и не решает лабораторную за студента. Истинные длины волн не должны отображаться в интерфейсе. Студент измеряет положение спектральной линии, самостоятельно рассчитывает результат и вводит его в журнал.

## Требования

- Сохранять физические вычисления независимыми от визуализации.
- Проверять единицы измерения: интерфейс использует см, мм и нм; вычисления переводятся в СИ.
- Поддерживать работу на обычном ноутбуке и встроенной графике.
- Сохранять Canvas-режим как резервный вариант при отсутствии WebGL.
- Не превращать интерфейс в калькулятор с готовыми ответами.
- Сохранять адаптивность и доступность элементов управления.
- Перед публикацией проверять основной сценарий: включение источника → измерение → запись → расчёт → проверка.
- Не создавать новый сайт, если существует `.openai/hosting.json`; обновлять связанный проект Sites.

## Текущий стек

- статические HTML, CSS и JavaScript;
- Three.js через ES-модули CDN;
- `localStorage` для локального журнала;
- OpenAI Sites для публикации.

## Исходные физические значения

- красная линия: 680 нм;
- зелёная линия: 530 нм;
- синяя линия: 465 нм;
- решётки: 100 и 200 штрихов/мм;
- порядки спектра: 1 и 2;
- расстояние до экрана: 30–80 см.

Подробности запуска и план развития находятся в `README.md` и `START_HERE.md`.
