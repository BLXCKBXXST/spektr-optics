# Лабораторная работа 7.3 — симулятор дифракционной решётки

Браузерный симулятор лабораторной работы по определению длины световой волны с помощью дифракционной решётки.

Опубликованная версия: https://lab-73-diffraction-simulator.blxckweed.chatgpt.site

## Что уже реализовано

- интерактивная оптическая установка «источник → решётка → экран»;
- трёхмерная сцена на Three.js и совместимый Canvas-режим без WebGL;
- выбор расстояния до экрана: 30–80 см;
- решётки 100 и 200 штрихов/мм;
- спектры первого и второго порядка;
- красная, зелёная и синяя спектральные линии;
- измерительный визир и шкала от −160 до +160 мм;
- журнал измерений;
- ввод и проверка рассчитанной длины волны с допуском 3%;
- сохранение журнала в `localStorage`;
- адаптивный интерфейс;
- WebMCP-инструменты для чтения и настройки состояния опыта.

## Запуск

Проект не требует установки зависимостей или сборки. Нужен любой локальный HTTP-сервер.

Из корня проекта:

```bash
python3 -m http.server 4173 --directory dist
```

После этого открыть:

```text
http://127.0.0.1:4173
```

Нельзя открывать `dist/index.html` напрямую через `file://`, потому что браузеру нужно загрузить JavaScript-модули.

## Структура

```text
dist/

└── app.js       — физика, сцена, измерения и журнал

.openai/
└── hosting.json — привязка к существующему сайту OpenAI Sites
```

Three.js загружается с CDN `cdn.jsdelivr.net`. Для полноценного 3D при первом открытии нужен доступ к интернету. Если WebGL недоступен, включается встроенная Canvas-визуализация.

## Физическая модель

Используются формулы:

```text
d · sin(φ) = k · λ
x = D · tan(φ)
sin(φ) = x / √(D² + x²)
λ = d · sin(φ) / k
```

Заложенные спектральные линии скрыты от студента:

- красная: 680 нм;
- зелёная: 530 нм;
- синяя: 465 нм.
