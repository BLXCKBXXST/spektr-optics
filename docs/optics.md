# Установка

## Согласованная модель

Координаты x — миллиметры рейки; свет идёт от больших к меньшим. Двигается **только экран**, остальные элементы предварительно настроены. «Согласовано» — решение для симулятора, не паспортные данные.

| Элемент | Положение / свойство |
| --- | --- |
| Источник | За 1000; край корпуса ≠ положение излучателя |
| Щель | 955; отдельный блок с одним гнездом |
| Линза | 900 |
| Решётка | 855; фиксированный период 10 мкм (100 штрихов/мм) |
| Фильтры | Красный и зелёный, съёмные; пропускание неизвестно |
| Экран | Старт 250; до решётки 605 мм |

Линза, решётка и фильтр занимают **три гнезда общего блока**. Без фильтра остаётся низкий штифт, не пустая высокая оправа. Каретка экрана смещена относительно его оптической плоскости.

## Требования к физике

Сейчас спектр иллюстративный. Неизвестны ширина щели и рабочей области решётки, спектр источника, пропускание фильтров.

- Белый свет: непрерывный спектр, все достаточно яркие порядки в пределах экрана.
- Один расчёт для всех ракурсов: положение экрана, щель, источник, фильтр.
- Фильтр меняет и центральный максимум; выключенный источник убирает всю световую картину.
- Щель — в фокальной плоскости линзы по методичке; 55 мм — не паспортное значение.
- Печатные шкалы — основной отсчёт. Подсказки их не перекрывают; числовой отсчёт ограничен печатной шкалой.
- XP/low-poly не ухудшают точность и читаемость; искусственное дрожание исключено.

## Вопросы преподавателю и обмеры

Приоритетные вопросы:

1. Ширина **входной щели** (не штрихов решётки): фиксированная или регулируемая? Какое значение для работы 7.3?
2. Паспортное фокусное расстояние линзы; маркировка/паспорт?
3. Маркировка красного и зелёного фильтров, диапазоны длин волн и пропускание? Сфотографировать маркировку.

Дополнительно: тип/маркировка источника; рабочая освещённая/штрихованная ширина решётки, **не размер оправы**.

| Проверить | Зафиксировать |
| --- | --- |
| Экран | Размер рабочей поверхности, единицы и мелкое деление; прямое фото шкалы с линейкой |
| Рейка и каретка | Деление, крайние положения, точка совмещения с отметкой, смещение оптической плоскости относительно указателя |
| Общий блок | Расположение трёх гнёзд; фото пустого гнезда и установленного фильтра |
| Спектр | Без фильтра, красный, зелёный: одно записанное положение экрана, одинаковая экспозиция; цвет телефона не абсолютное измерение |

Не касаться рабочей поверхности решётки. Не разбирать/переставлять приборы без разрешения.
