# Руководство

## Запуск

Скачайте [spektr.html](../dist/spektr.html) и откройте его в браузере. Это единственный необходимый файл: код, оформление и изображение установки находятся внутри. Интернет и WebGL не используются.

Требуется браузер с JavaScript и Canvas 2D. На телефонах статический просмотрщик вложений может не запускать код; нужен полноценный браузер с возможностью открытия локального HTML. Оформление Windows XP не означает поддержку браузеров эпохи XP.

## Управление

Верхнее окно содержит установку, нижнее — все элементы управления. Размер сцены меняется вместе с окном браузера. В очень низком окне появляется вертикальная прокрутка.

| Элемент | Действие |
| --- | --- |
| Ракурсы | Общий вид, сверху, оптика крупно, экран крупно |
| Подписи | Названия приборов |
| Значения | Числовые указатели на скамье и линейка на экране |
| Источник света | Включение и выключение света |
| Фильтр | Без фильтра, зелёный или красный |
| ← Экран → | Следующая отметка, кратная 10: из 303 вправо — 310, влево — 300 |

Перетаскивайте экран мышью или пальцем в общем виде и виде сверху: шаг составляет 1 мм. В крупном виде экран не перемещается. При включённых «Значениях» линейка следует за мышью; после касания остаётся на выбранном месте. Число показывает расстояние от центрального нуля экрана, а не продольную координату каретки. Печатная шкала остаётся основным средством отсчёта.

## Сохранение

Браузер запоминает настройки, если разрешено локальное хранилище. Без него программа работает, но настройки после закрытия не сохраняются. Вместе с HTML-файлом настройки на другое устройство не переносятся; начальная позиция экрана — 250 мм.

## Проверки и ограничения

Проверены Chromium, офлайн-запуск через `file://`, отключённый WebGL, недоступное хранилище, касания и окна от 320×568 до 1920×1080, включая горизонтальный размер 812×375. Реальные Android/iOS-устройства, Firefox и Safari пока не проверены.

Это визуальный прототип: форма и яркость спектра, свойства светофильтров и часть размеров ещё требуют калибровки. [Параметры и дальнейшие задачи](specification.md).

## Тестовое окружение разработчика

После `npm ci` установите Chromium командой `npx playwright install chromium`. На Linux при необходимости используйте `npx playwright install --with-deps chromium` для установки его системных библиотек. Проверки запускаются через `npm test`; результаты сохраняются в игнорируемую папку `test-results/`.

Для уже установленного браузера задайте `SPEKTR_BROWSER_EXECUTABLE`. Дополнительные настройки: `SPEKTR_PLAYWRIGHT_MODULE` — путь к установленному Playwright, `SPEKTR_TEST_FILE` — альтернативный HTML, `SPEKTR_TEST_OUTPUT` — каталог результатов. Эти настройки не нужны пользователю симулятора.
