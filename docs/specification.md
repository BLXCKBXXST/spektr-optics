# Параметры и развитие

## Назначение

«Спектр» моделирует реальную оптическую установку. Пользователь наблюдает картину и считывает шкалы самостоятельно. Учебные задания, журнал, проверка ответов и автоматическое выполнение лабораторной не входят в проект.

Оформление: спокойная светлая тема Windows XP и малополигональная геометрия PS1, без искусственного дрожания и ухудшения шкал. Верхнее окно показывает установку, нижнее содержит всё управление. Минимальная высота верхнего окна — 320 пикселей; при нехватке места страница прокручивается.

## Подтверждённые договорённости

Продольная ось x измеряется в миллиметрах по рейке. Свет идёт от больших координат к меньшим.

| Элемент | Положение / свойство |
| --- | --- |
| Источник | За отметкой 1000; край корпуса не равен положению излучателя |
| Щель | x = 955, отдельный одногнёздный блок |
| Линза | x = 900 |
| Решётка | x = 855; период 10 мкм, 100 штрихов/мм |
| Экран | На старте x = 250; только он перемещается |
| Решётка — экран | Начальное расстояние 605 мм |
| Фильтры | Красный и зелёный, съёмные |

Линза, решётка и гнездо фильтра стоят на одном трёхгнёздном основании. При снятом фильтре остаётся низкий штифт. Щель находится в отдельной круглой оправе. Экран имеет смещённую относительно оптической плоскости каретку.

## Отображение и физика

Основные средства измерения — нанесённые на установку шкалы. Вспомогательные указатели не должны перекрывать их. «Подписи» показывают названия, «Значения» — координаты и поперечную линейку. На экране числовой отсчёт не продолжается за пределы печатной шкалы.

Текущий спектр иллюстративный. Целевая модель должна показывать непрерывный спектр белого света и все достаточно яркие порядки, попадающие на экран. Расчёты для всех ракурсов должны быть едиными. Светофильтр влияет и на центральный максимум; при выключении источника исчезает вся световая картина.

По методичке, раздел 7.3, стр. 37–38, щель находится в фокальной плоскости линзы. В симуляторе оптика считается заранее настроенной: линза, решётка и щель не перемещаются.

## Следующие этапы

1. Отделить состояние оборудования, физические расчёты и отображение. Привести вычисления к единой системе единиц; проверить расчёты до визуальной детализации.
2. Откалибровать ширину щели, параметры источника и пропускание фильтров. Подключить единый расчёт спектра к каждому ракурсу.
3. Сверить габариты и шкалы с реальной установкой, уточнить пределы хода экрана и смещения держателей.
4. Завершить проверку физических результатов, слабых устройств, браузеров и реального сенсорного управления, сохранив один офлайн-HTML.
