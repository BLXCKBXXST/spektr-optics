# Спектр

Оптическая скамья в одном HTML-файле: светлый интерфейс Windows XP, малополигональная установка и работа без интернета. Пользователь управляет оборудованием и считывает шкалы сам — программа не выполняет лабораторную за него.

**Сейчас это визуальный прототип.** Управление работает, но физическая достоверность формы и яркости спектра ещё не подтверждена.

## Запуск

1. Откройте [файл spektr.html](dist/spektr.html) в этом репозитории.
2. Нажмите **Download raw file**, чтобы скачать его, а не сохранить страницу GitHub.
3. Откройте скачанный файл в браузере.

Это всё: установка, сервер, интернет и дополнительные файлы не нужны. Требуется браузер с JavaScript и Canvas 2D; WebGL не используется. Стиль Windows XP — только оформление, а не обещание поддержки старых браузеров.

**Если на телефоне виден код или неподвижный предпросмотр:** откройте файл именно в браузере, а не в просмотрщике вложений. Возможность запуска локального HTML зависит от системы. Пока подтверждена работа в Chromium; реальные Android/iOS-устройства, Firefox и Safari ещё не проверены.

## Управление

Верхнее окно показывает установку, нижнее содержит всё управление. Страница подстраивается под размер окна; при нехватке высоты появляется прокрутка.

| Что сделать | Как |
| --- | --- |
| Выбрать ракурс | «Общий вид», «Сверху», «Оптика» или «Экран» |
| Включить свет или сменить фильтр | Галочка «Источник света» и список «Фильтр»; доступны красный, зелёный и отсутствие фильтра |
| Показать названия приборов | Галочка «Подписи» |
| Показать координаты и линейку | Галочка «Значения», независимо от подписей |
| Переместить экран точно | Перетащить мышью или пальцем в общем/верхнем виде; шаг 1 мм |
| Переместить экран стрелками | К следующей отметке, кратной 10: из 303 вправо — 310, влево — 300 |
| Измерить расстояние на экране | Выбрать «Экран», включить «Значения» и навести курсор или коснуться поверхности |

В крупном виде экран нельзя перетаскивать. Линейка измеряет поперечное расстояние от центрального нуля, а не положение каретки на скамье; после касания она остаётся на выбранном месте. Основной способ отсчёта — печатные шкалы. Остальные приборы неподвижны.

**Сохранение:** настройки запоминаются в этом браузере, если разрешено локальное хранилище. Без него программа работает, но настройки после закрытия теряются. Копирование HTML на другое устройство не переносит сохранённое состояние.

## Что дальше

Уже реализованы модель установки, четыре ракурса, фильтры, перемещение экрана, линейка и адаптивные окна. Проверены офлайн-запуск, работа без WebGL, отказ локального хранилища, эмуляция касаний и размеры окна от 320×568 до 1920×1080.

Ближайшая работа — физическая модель, а не новые панели интерфейса:

1. Разделить состояние оборудования, оптические расчёты и отображение; проверить единицы и расчёты.
2. Уточнить щель, источник и фильтры; подключить единый расчёт спектра ко всем ракурсам.
3. Сверить размеры и шкалы с установкой, затем проверить физические результаты и реальные мобильные устройства.

Для этой работы есть один [справочник установки](docs/optics.md): конструкция, все координаты, временные оценки и полный список вопросов преподавателю. Для запуска и использования симулятора он не требуется.

## Разработка

### Подготовить проект

Нужны Git и Node.js 20+. Репозиторий закрытый: используйте GitHub-аккаунт с доступом.

```sh
git clone https://github.com/BLXCKBXXST/spektr-optics.git
cd spektr-optics
npm ci
npx playwright install chromium
npm test
```

`npm test` пересобирает программу и запускает проверки офлайн-работы, адаптивности, измерений и управления. Скриншоты и результаты появляются в `test-results/` и не попадают в Git. Node.js и Playwright нужны только разработчику, не пользователю готового HTML.

### Внести изменение

| Файл или каталог | За что отвечает |
| --- | --- |
| `src/simulator.html` | Установка, отрисовка, элементы управления и состояние |
| `src/shell.html` | Оболочка автономной страницы и её размер |
| `scripts/build.cjs` | Объединение исходников в один HTML |
| `tests/` | Проверки поведения программы |

После правок выполните `npm test` и включите обновлённый `dist/spektr.html` в коммит вместе с исходниками. Если нужна только сборка, достаточно `npm run build`; для неё установка пакетов не требуется. Проверку физики сверяйте со справочником установки, не превращая оценки в подтверждённые данные.

<details>
<summary>Если тестовый браузер не запускается или нужен нестандартный путь</summary>

На Linux системные библиотеки Chromium можно установить командой `npx playwright install --with-deps chromium`. Для уже установленного браузера задайте `SPEKTR_BROWSER_EXECUTABLE`.

| Переменная | Назначение |
| --- | --- |
| `SPEKTR_PLAYWRIGHT_MODULE` | Путь к установленному Playwright |
| `SPEKTR_TEST_FILE` | Альтернативный HTML для проверки |
| `SPEKTR_TEST_OUTPUT` | Другой каталог результатов |

Эти настройки относятся только к тестам и не нужны при открытии симулятора.

</details>

История изменений, старые версии и архив передачи доступны в [коммитах Git](https://github.com/BLXCKBXXST/spektr-optics/commits/main/). Некоторые ранние промежуточные снимки не сохранились; история не восстанавливалась задним числом.
