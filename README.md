# Спектр

Оптическая скамья в одном HTML-файле. Светлый интерфейс Windows XP, малополигональная установка и работа без интернета.

**[Скачать HTML](dist/spektr.html)** · [Руководство](docs/usage.md) · [Параметры и план](docs/specification.md)

![Спектр: оптическая установка и отдельное окно управления](docs/assets/preview.png)

## Запуск

Откройте [`dist/spektr.html`](dist/spektr.html), нажмите **Download raw file** и запустите скачанный файл в браузере. Установка, сервер, внешние библиотеки и WebGL не нужны.

Нужен браузер с JavaScript и Canvas 2D. Проверено в Chromium; совместимость с конкретными телефонами ещё предстоит проверить.

## Возможности

- Четыре ракурса: общий вид, сверху, оптика и экран.
- Источник света, красный и зелёный фильтры.
- Подвижный экран, шкалы и вспомогательная линейка.
- Два адаптивных XP-окна, управление мышью и касанием.

**Статус: визуальный прототип.** Физическая достоверность яркости и формы спектра пока не подтверждена. Симулятор не выполняет лабораторную за пользователя.

## Разработка

Node.js 20+ нужен только для сборки и тестов; готовый HTML работает без него.

```sh
npm ci
npx playwright install chromium
npm test
```

Для одной сборки достаточно `npm run build` — установка пакетов не требуется. Результат: `dist/spektr.html`.

| Каталог | Содержимое |
| --- | --- |
| `src/` | Симулятор и оболочка страницы |
| `scripts/` | Сборка автономного файла |
| `tests/` | Проверки интерфейса, управления и офлайн-работы |
| `docs/` | Руководство, параметры и вопросы преподавателю |
| `dist/` | Готовый файл для запуска |

[История изменений](https://github.com/BLXCKBXXST/spektr-optics/commits/main/) хранится в Git. Старые версии и архив передачи доступны в прежних коммитах.
