# Спектр

Автономный симулятор оптической установки: спокойный интерфейс Windows XP и малополигональная модель. Только оборудование и наблюдение спектра — без выполнения лабораторной, журнала и проверки ответов.

## Запуск

Скачайте [`portable/spektr.html`](portable/spektr.html) через кнопку скачивания файла на GitHub и откройте его в браузере. **Нужен только этот один файл**, без интернета, установки, сервера, библиотек и WebGL. Просмотр исходного кода на странице GitHub сам по себе программу не запускает.

Требуется браузер с JavaScript и Canvas 2D. На телефоне нужен именно браузер, а не статический просмотрщик вложений. Совместимость с буквально любым устройством не гарантируется. Подробности — в [PORTABLE.md](PORTABLE.md).

## Интерфейс

- Верхнее XP-окно — установка, занимающая доступное место по ширине и высоте.
- Нижнее отдельное XP-окно — всё управление: ракурсы, подписи, значения, источник света, фильтр и положение экрана.
- В низком окне появляется обычная вертикальная прокрутка: установка не сжимается до нечитаемой миниатюры. Управление не накладывается на изображение.
- Перетаскивание экрана — с шагом 1 мм; стрелки — к следующей отметке, кратной 10, в выбранном направлении.

Это ещё **визуальный прототип**. Яркость, форма линий и пропускание фильтров не прошли физическую верификацию. План дальнейшей работы и подтверждённые/приблизительные параметры сохранены в [SIMULATOR_PLAN.md](SIMULATOR_PLAN.md) и [DESIGN_STAGE_1.md](DESIGN_STAGE_1.md).

## Продолжить разработку на другом устройстве

1. Клонируйте закрытый репозиторий под аккаунтом с доступом.
2. Откройте эту папку в редакторе или чате разработки и попросите прочитать `AGENTS.md`, `SIMULATOR_PLAN.md`, `DESIGN_STAGE_1.md` и `HISTORY.md`.
3. Редактируемый исходник — `src/optics-xp-layout.html`. Для сборки выполните `node tools/export-portable.cjs` или `npm run build`.
4. Для тестов разработчика: `npm ci`, затем `npx playwright install chromium`, затем `npm test`. На Linux браузеру могут потребоваться системные библиотеки. Можно указать уже установленный браузер через `SPEKTR_BROWSER_EXECUTABLE`.

Node.js и Playwright нужны **только разработчику**, не пользователю готового HTML. Сборщик использует стандартные модули Node.js; для пересборки установка пакетов не требуется.

## Файлы

- `src/` — исходник текущего симулятора.
- `portable/spektr.html` — готовый автономный файл.
- `tools/` и `tests/` — сборка и проверки.
- `history/` — старое приложение и оригинальный архив передачи; не текущая версия и не новые требования.
- `QUESTIONS_FOR_TEACHER.md` — вопросы преподавателю для уточнения реальной установки.

История: исходный коммит от 5 октября сохранён с первоначальным хешем. Доступное состояние прототипа импортировано отдельным коммитом 7 октября, после чего записана новая компоновка. Несохранившиеся промежуточные версии не придуманы и не датированы задним числом — см. [HISTORY.md](HISTORY.md).
