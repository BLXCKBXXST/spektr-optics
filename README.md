# Спектр

Оптический симулятор: интерфейс Windows XP, low-poly установка, один офлайн-файл. Без автоматического выполнения лабораторной.

![Спектр](docs/assets/preview.png)

## Запуск

Скачайте [spektr.html](dist/spektr.html) кнопкой **Download raw file** и откройте в браузере. Установка и интернет не нужны.

Нужны JavaScript и Canvas 2D, не WebGL. Проверен Chromium; Firefox, Safari и реальные телефоны ещё не проверены. На телефоне нужен браузер, открывающий локальный HTML, а не просмотрщик вложений.

## Управление

Все кнопки — в нижнем окне. Перемещается только экран.

| Элемент | Действие |
| --- | --- |
| Ракурс | Общий вид, сверху, оптика, экран |
| Источник / фильтр | Свет вкл./выкл.; без фильтра, красный, зелёный |
| Подписи | Названия приборов |
| Значения | Координаты и линейка, независимо от подписей |
| Перетаскивание | В общем/верхнем виде, мышью или пальцем; шаг 1 мм |
| ← Экран → | Следующее кратное 10: из 303 влево — 300, вправо — 310 |

Линейка: ракурс «Экран» → «Значения» → наведение или касание. Отсчёт от центра; после касания сохраняется. Основной отсчёт — по печатным шкалам.

Настройки сохраняются локально, если разрешено хранилище браузера; с файлом не переносятся.

<details>
<summary>Разработка</summary>

Нужны Git, Node.js 20+ и доступ к закрытому репозиторию.

```sh
git clone https://github.com/BLXCKBXXST/spektr-optics.git
cd spektr-optics
npm ci
npx playwright install chromium
npm test
```

Исходники: `src/simulator.html` — установка и управление, `src/shell.html` — оболочка. Сборка — `scripts/build.cjs`, проверки — `tests/`.

После правок: `npm test` пересобирает HTML и проверяет офлайн-работу, адаптивность и управление. Коммитьте `dist/spektr.html` вместе с исходниками; `test-results/` игнорируется. Только сборка: `npm run build`, без установки пакетов.

На Linux при нехватке библиотек: `npx playwright install --with-deps chromium`. Свой браузер: `SPEKTR_BROWSER_EXECUTABLE`. Всё это нужно только для разработки.

</details>
