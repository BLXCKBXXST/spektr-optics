# Разработка «Спектра»

- README содержит полный путь пользователя и разработчика, текущее состояние и план. Все параметры установки, допущения и вопросы преподавателю находятся в `docs/optics.md`.
- Только симулятор оборудования: без заданий, журнала измерений, оценок и автоматического выполнения лабораторной.
- Исходники — `src/simulator.html` и `src/shell.html`. Сборка: `npm run build`; результат `dist/spektr.html` хранится в Git для скачивания.
- Сохранять один автономный HTML без CDN, сервера и обязательного WebGL/WebGPU. Зависимости тестов не нужны для запуска программы.
- Перемещается только экран. Сохранять согласованные координаты, читаемость шкал, два XP-окна и независимость «Подписей» и «Значений».
- После изменений выполнять `npm test`. Результаты тестов и временные скриншоты не коммитить. Старые коммиты не переписывать.
- Не добавлять архивы переписки, локальные пути, старые сборки, фотографии, методичку или секреты. Для README достаточно одного актуального скриншота.
- Не дробить один сценарий чтения между документами: запуск, управление и разработка должны быть понятны из README; справочник установки нужен только для углубления в модель.
- Писать простыми полными предложениями. Краткость не должна превращать инструкции в обрывки фраз или цепочки терминов без объяснения.
