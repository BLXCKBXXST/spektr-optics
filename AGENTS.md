# Работа над «Спектром»

- Актуальная цель — только симулятор оборудования; не добавлять задания, журнал измерений, оценку ответов или автоматическое выполнение лабораторной.
- Перед изменениями читать `SIMULATOR_PLAN.md`, `DESIGN_STAGE_1.md`, `PORTABLE.md` и `HISTORY.md`.
- Актуальный исходник: `src/optics-xp-layout.html`; оболочка автономного файла: `tools/portable-shell.html`. После правок пересобрать `portable/spektr.html` командой `node tools/export-portable.cjs`.
- Готовая программа должна оставаться одним офлайн-HTML без CDN, загружаемых ресурсов, сервера и обязательного WebGL/WebGPU. Зависимости тестов не являются зависимостями запуска.
- Геометрия и шкалы должны соответствовать согласованным координатам; непроверенные параметры явно отделять от подтверждённых. Физика нынешнего прототипа ещё не верифицирована.
- Всё управление находится в отдельном нижнем XP-окне. Верхнее окно — только установка. Сохранять адаптивность, клавиатурное и сенсорное управление, независимость «Подписей» и «Значений».
- `history/` — справочный архив. Не изменять его как рабочее приложение, не применять прежние учебные требования к текущему симулятору. Файл `history/legacy-site/.openai/hosting.json` относится только к старой публикации: не использовать его для нового деплоя.
- Историю сохранять обычными новыми коммитами; не переписывать ранний коммит, не имитировать отсутствующие версии задним числом.
- Перед передачей запускать `npm test` после настройки тестового окружения. Проверять отсутствие сетевых запросов и переполнения интерфейса, крайние положения экрана, работу фильтров и линейки.
- Не публиковать методичку, фотографии, полные личные переписки и секреты без отдельного разрешения. Репозиторий создан закрытым.
